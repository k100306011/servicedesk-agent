# KB-005: Displays, printers, and workplace hardware

- Owner: Workplace Technology
- Last reviewed: 2026-07-18
- Status: Active
- Applies to: Company-managed workplace devices

For displays, confirm power, cable connection, docking-station connection, and
operating-system display detection. Ask the user to reconnect the dock and use
the detect-displays function. Record dock and monitor models if the issue
remains.

For printers, confirm the user is on the correct network, the printer is
online, and the queue is not paused. Clear only the user's failed jobs before
reconnecting the published printer. Do not instruct users to assign an IP.

Create a `Hardware` ticket for physical failures and a `Network` ticket when
multiple users lose connectivity to the same printer. A swollen or overheating
battery requires the user to stop using and charging the device immediately.
