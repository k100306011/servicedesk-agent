# KB-008: Security alerts and suspicious activity

- Owner: Security Operations
- Last reviewed: 2026-08-22
- Status: Active
- Applies to: All users and company devices

For suspected phishing, unexpected MFA prompts, malware alerts, lost devices,
or possible account compromise, instruct the user to stop interacting with the
suspicious content and contact the Security Hotline.

Create a high-priority `Security` ticket with a concise description, affected
device or account identifier, time observed, and actions already taken.

Do not request passwords, MFA codes, private keys, recovery codes, or full
payment-card data. Do not tell the user to disable endpoint protection or
delete evidence. Do not promise that an account or device is safe. Security
Operations determines containment, evidence collection, credential reset,
device isolation, and closure.
