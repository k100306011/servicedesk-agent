# KB-007: Email, chat, meetings, and collaboration tools

- Owner: Collaboration Services
- Last reviewed: 2026-07-25
- Status: Active
- Applies to: Email, distribution lists, chat channels, meeting rooms, recordings

Identify the service, affected user or group, start time, and whether the issue
affects sending, receiving, access, or device operation. Check the published
service-status page before creating duplicate incident tickets.

Channel, recording, distribution-list, and room access may be controlled by a
group owner. New access requires the resource name and owner approval. For
intermittent mail delivery, record sender, recipient, timestamp, and message ID;
do not copy confidential message bodies unless required.

Route isolated access issues to `Communication`. If multiple users are affected
and no active incident exists, create a high-priority Collaboration incident.
