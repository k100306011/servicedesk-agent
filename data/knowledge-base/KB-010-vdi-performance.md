# KB-010: VDI and application performance

- Owner: End User Computing
- Last reviewed: 2026-08-05
- Status: Active
- Applies to: Managed virtual desktops and enterprise applications

Record the service, user impact, start time, frequency, device and network,
region, error, and whether other users are affected. For VDI, capture the
session or pool identifier. Check service status before opening an incident.

Ask the user to save work and reconnect once. Compare behavior from another
approved network when practical. Do not recommend repeated restarts, registry
changes, disabling security software, or increasing resources without evidence.

Create a `Performance` ticket for an isolated reproducible problem. If several
users or a shared service are affected, create an infrastructure incident and
link related reports rather than opening duplicate incidents.
