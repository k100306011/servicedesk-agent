# KB-003: Remote access, VPN, and remote desktop

- Owner: End User Computing
- Last reviewed: 2026-07-30
- Status: Active
- Applies to: Company-managed laptops and approved mobile devices

Confirm the device is company managed, has internet access, and reports as
compliant. Record the client, operating system, error, and whether the problem
affects VPN, remote desktop, or file transfer.

For expired-token or authentication errors, ask the user to disconnect, sign
out of the client, sign in again, and reconnect. For remote desktop, verify the
target computer is powered on and the user has been assigned remote access.

Do not advise users to disable endpoint protection, firewall controls, device
compliance, or certificate validation. Create a `RemoteWork` ticket when the
approved client remains unavailable. Route suspected compromise to Security.
